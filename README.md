# MIMUW-MRJP-Instant-Compiler
W projekcie wykorzystuje biblioteke do formatowania napisow fmt:
https://github.com/fmtlib/fmt

Katalog lib zawiera skompilowana biblioteke fmt oraz includy

Dodatkowe testy zostaly pobrane z repozytorium na githubie.

Kompilatory napisalem samodzielnie.

W katalogu src znajduja sie glowne pliki projektu oraz te wygenerowane przez bnfc
